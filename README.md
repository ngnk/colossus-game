# Colossus

A classroom negotiation game about the xAI data center in Memphis (IDS 704 case study).

- **Class:** open https://ngnk.github.io/colossus-game/ on the projector laptop. Five players scan the QR code, one per character.
- **Testing alone:** open https://ngnk.github.io/colossus-game/?test and press Start: every seat nobody took on a phone is played on the laptop.

No logins or installs for players.
